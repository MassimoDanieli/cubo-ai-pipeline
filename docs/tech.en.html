Technical Overview – AI Pipeline

This page describes in detail the architecture, tools, and automation used in the cubo-ai-pipeline project.

Goal

Demonstrate a DevOps pipeline with AI, even for a minimal web app: review, test proposals, changelog and deploy are automated.

Project Structure

  • Frontend: standalone HTML + JavaScript
  • Main function: calculate cube volume (calcolaEDisegna())
  • Deploy: GitHub Pages via /docs folder

CI/CD Pipeline

  • GitHub Actions on PRs, pushes and tags
  • ESLint and Jest with coverage on every push and PR
  • AI review of the diff on every PR, as one comment updated in place
  • Jest test proposals for changed code
  • Changelog written on every v* tag and proposed as a PR
  • @claude assistant in PR and issue comments

AI review (v2, November 2026)

The AI steps use the reusable workflows from ai-devops-starter-kit. The model gets the PR diff with context and returns structured findings: file, line, severity, category and a proposed fix. When there is nothing worth flagging it stays quiet. The provider (Anthropic, OpenAI or a local model) is a single parameter.

Agentic assistant

Mentioning @claude in a comment starts Claude Code on the runner via the official anthropics/claude-code-action: it reads the repository, runs the tests and answers or proposes a change.

v1 (May 2025)

The first version used three Python scripts calling gpt-3.5-turbo (file-by-file review, generated tests, changelog on every push). OpenAI shut that model down on 23 October 2026 and the scripts were removed.

Testing

Initially using jsdom, tests were then refactored to CommonJS to remove unnecessary dependencies and ensure GitHub Actions compatibility.

function calcolaVolume(input) {
  const lato = parseFloat(input);
  if (isNaN(lato) || lato < 0) return 'Errore';
  return `Il volume è: ${Math.pow(lato, 3)}`;
}

module.exports = { calcolaVolume };

Example Jest test:

const { calcolaVolume } = require('../scripts/main');

test('volume corretto per 3', () => {
  expect(calcolaVolume('3')).toBe('Il volume è: 27');
});
