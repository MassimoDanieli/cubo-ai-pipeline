Approfondimento Tecnico – Pipeline IA

Questa pagina descrive in dettaglio l'architettura, gli strumenti e le automazioni utilizzate nel progetto cubo-ai-pipeline.

Obiettivo

Dimostrare una pipeline DevOps con l'IA, anche per una webapp minima: review, proposte di test, changelog e deploy sono automatizzati.

Struttura del progetto

  • Frontend: HTML + JavaScript standalone
  • Funzione: Calcolo volume di un cubo (calcolaEDisegna())
  • Deploy: GitHub Pages via cartella /docs

Pipeline CI/CD

  • GitHub Actions su PR, push e tag
  • ESLint e Jest con coverage su ogni push e PR
  • Review IA del diff su ogni PR, con un solo commento aggiornato
  • Proposte di test Jest per il codice cambiato
  • Changelog generato su ogni tag v* e proposto come PR
  • Assistente @claude nei commenti di PR e issue

Review con l'IA (v2, novembre 2026)

I passi IA usano i workflow riutilizzabili di ai-devops-starter-kit. Il modello riceve il diff della PR con il contesto e restituisce risultati strutturati: file, riga, gravità, categoria e correzione proposta. Se non c'è niente da segnalare, non commenta. Il fornitore (Anthropic, OpenAI o un modello locale) si sceglie con un parametro.

Assistente agentico

Con @claude in un commento, l'action ufficiale anthropics/claude-code-action avvia Claude Code sul runner: legge il repository, esegue i test e risponde o propone una modifica.

v1 (maggio 2025)

La prima versione usava tre script Python con gpt-3.5-turbo (review file per file, test generati, changelog a ogni push). Il modello è stato spento da OpenAI il 23 ottobre 2026; gli script sono stati rimossi.

Testing

Inizialmente i test erano basati su jsdom, ma poi sono stati refactorati in CommonJS per evitare dipendenze non compatibili con GitHub Actions.

function calcolaVolume(input) {
  const lato = parseFloat(input);
  if (isNaN(lato) || lato < 0) return 'Errore';
  return `Il volume è: ${Math.pow(lato, 3)}`;
}

module.exports = { calcolaVolume };

Esempio test con Jest:

const { calcolaVolume } = require('../scripts/main');

test('volume corretto per 3', () => {
  expect(calcolaVolume('3')).toBe('Il volume è: 27');
});
